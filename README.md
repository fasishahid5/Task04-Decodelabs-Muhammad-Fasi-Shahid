#  Password Generator – Python Project

A simple Python-based secure password generator that creates random passwords using letters, numbers, and special characters.

---

##  Features

- Generates strong random passwords
- User defines password length
- Uses letters, digits, and special characters
- Secure randomness using Python's `random` module

---

##  Technologies Used

- Python 3
- random module
- string module
- loops & string manipulation
